# RISEN CARE Connect

RISEN CARE Connectは、障害福祉事業所で使用されている外部システムや
MySQLデータベースとRISEN CAREを接続するためのデータ連携基盤です。

## コンセプト

単なるデータベース接続ツールではなく、接続先ごとに異なる項目名を
「RISEN CARE標準データモデル」へマッピングし、AI・API・画面で
共通利用できる状態に整えます。

## 基本フロー

1. データベース接続
2. テーブル選択
3. カラム取得
4. RISEN CARE標準項目へのマッピング
5. マッピング設定保存
6. データ同期
7. AIによる検索・通知・提案

## 初期対応領域

介護保険よりも先に、障害福祉領域を標準対応します。

主な対象情報：

- 利用者基本情報
- 受給者証情報
- 連絡先
- 緊急連絡先
- 契約情報
- サービス提供記録
- 支援記録
- バイタル情報
