# RISEN CARE 標準データモデル Ver1.0

## 目的

RISEN CARE Connectで取得したデータを、
システム固有の構造ではなく、RISEN CARE標準データモデルへ統一する。

この標準データモデルは、

- RISEN CARE Connect
- AIKO
- API
- BI・分析
- 他社システム連携

の共通基盤となる。

---

# 設計原則

## 利用者中心設計

RISEN CAREでは、システム単位ではなく利用者を中心にデータを管理する。

利用者に紐づく情報として、

- 受給者証
- 契約
- サービス
- 支援記録
- 緊急連絡先

などを関連付ける。

---

## AIファースト設計

RISEN CAREでは、

「何を保存するか」

ではなく、

「AIKOが何を答えられるようにするか」

を基準にデータモデルを設計する。

# データモデルの基本思想

RISEN CAREの標準データモデルは、
単なるデータベース設計ではない。

Connect・AIKO・API・分析基盤が共通で利用する
プラットフォームの基盤となる。

すべての機能は、この標準データモデルを中心に設計・実装する。
