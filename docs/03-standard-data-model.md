# RISEN CARE標準データモデル Ver1.0

## 1. 利用者基本情報

- 利用者ID
- 利用者名
- フリガナ
- 性別
- 生年月日
- 郵便番号
- 住所
- 電話番号
- 携帯電話番号
- メールアドレス
- 顔写真

年齢は生年月日から計算し、原則として保存項目にはしません。

## 2. 受給者証情報

- 受給者証ID
- 受給者証番号
- 受給者証種別
- 施設種別
- サービス種別
- 支給市町村コード
- 支給市町村名
- 支給都道府県名
- 交付年月日
- 適用開始日
- 適用終了日
- 障害支援区分
- 障害種別
- 備考

受給者証は更新によって複数世代が発生するため、
利用者テーブルに直接持たせず、別テーブルで履歴管理します。

## 3. 連絡先情報

本人の連絡先：

- 固定電話番号
- 携帯電話番号
- メールアドレス

FAX番号は必須の標準項目にはせず、
利用施設の必要に応じて拡張項目として追加可能にします。

## 4. 緊急連絡先

緊急連絡先は複数登録可能とします。

- 利用者ID
- 優先順位
- 氏名
- フリガナ
- 続柄
- 役割
- 固定電話番号
- 携帯電話番号
- メールアドレス
- 住所
- 連絡可能時間
- 推奨連絡方法
- 緊急時のみ
- 備考
- 有効／無効
- AI回答可否

## 5. システム共通情報

- 外部ID
- データソース
- 作成日時
- 更新日時
- 同期日時
- 作成者
- 更新者
