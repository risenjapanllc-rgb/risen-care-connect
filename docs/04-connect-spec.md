# RISEN CARE Connect 仕様書 Ver1.0

## 目的

RISEN CARE Connectは、各社システムのデータを
RISEN CARE標準データモデルへマッピングするためのデータ連携基盤である。

---

# データ取込フロー

1. データベース接続
2. テーブル一覧取得
3. カラム一覧取得
4. 標準データモデル選択
5. カラムマッピング
6. マッピング保存
7. データ同期
8. AIKO利用

---

# マッピング例

| MySQLカラム | RISEN CARE標準項目 |
|---|---|
| name | 利用者名 |
| birthday | 生年月日 |
| zip | 郵便番号 |
| address | 住所 |
| phone | 電話番号 |
| mobile | 携帯電話番号 |
| email | メールアドレス |

---

# マッピング対象

マッピングでは、外部システム側の次の情報を取得する。

- データソース
- データベース名
- テーブル名
- カラム名
- データ型
- NULL許可
- 主キー
- コメント

これらをRISEN CARE標準項目へ対応付ける。

---

# マッピング保存

保存する情報は次のとおりとする。

- マッピングID
- 接続先ID
- データソース
- 外部テーブル名
- 外部カラム名
- 外部データ型
- RISEN CAREエンティティ名
- RISEN CARE標準項目名
- 変換ルール
- 必須／任意
- 有効／無効
- 作成日時
- 更新日時
- 作成者
- 更新者

---

# 変換ルール

必要に応じて、同期前にデータ変換を行う。

例：

- 日付形式の統一
- 全角・半角の統一
- 電話番号の正規化
- 郵便番号の正規化
- 性別コードの変換
- 有効／無効コードの変換
- 空文字とNULLの統一
- 外部コードとRISEN CARE標準コードの対応付け

---
